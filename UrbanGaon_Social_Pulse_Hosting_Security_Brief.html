Social Pulse Dashboard: Hosting & Data Security Brief
Prepared for Executive Leadership & Board Review • Clarifying Data Flow, Hosting Options & Privacy Safeguards
🔒 Direct Answer to the Core Privacy Question:
"If we host the frontend via Vercel on social.urbangaon.com, does our data go to a third party?"
NO. Business data, customer analytics, and weekly records NEVER reside on the web host (neither BigRock nor Vercel). All data is stored exclusively in our encrypted MongoDB Atlas Enterprise Cloud cluster. The web host acts strictly as a stateless display engine.
1. Understanding Where Our Corporate Data Actually Lives
There is a clear architectural separation between where our application code renders and where our confidential records reside:
DATABASE LAYER (CONFIDENTIAL RECORDS)
MongoDB Atlas Enterprise Cluster
• What Lives Here: All social media metrics, historical week entries, customer reviews, ratings, and encrypted passwords.
• Encryption: Encrypted in transit (TLS 1.3) and encrypted at rest (AES-256).
• Access: Protected by IP whitelisting and credentials. Isolated from any web host.
APPLICATION LAYER (COMPUTE ENGINE)
Web Hosting Platform (Vercel / Server)
• What Lives Here: Only compiled React UI code, CSS styling, and stateless API handlers.
• Zero Data Retention: Does NOT save, log, cache, or inspect database records.
• Pure Bridge: Simply delivers the HTML/JS interface to the user's browser.
2. BigRock Shared Hosting vs. Vercel Cloud Security Comparison
A technical risk evaluation between BigRock cPanel shared hosting and modern enterprise edge infrastructure:
Security Factor BigRock Shared cPanel Hosting Vercel Cloud Edge Platform
Server Architecture Multi-tenant shared server (hundreds of external websites share the same disk & IP). Sandboxed isolated micro-containers. Zero cross-tenant data exposure.
Security Compliance Basic shared hosting standard. SOC2 Type II, ISO 27001, GDPR certified enterprise infrastructure.
Trusted Industry Users Personal blogs, small local WordPress sites. OpenAI (ChatGPT UI), Nike, Uber, TikTok, The Washington Post.
Runtime Compatibility ❌ Missing Node.js runtime (jailshell blocks Next.js 16 execution). ✔ Native Next.js 16 runtime created by the authors of Next.js.
Brand / Domain Privacy Runs on social.urbangaon.com Runs on social.urbangaon.com (100% company domain, zero external branding).

EXECUTIVE DECISION MATRIX & DEPLOYMENT PATHS
DECISION ROADMAP
Executive Decision Matrix: 3 Viable Hosting Paths
Leadership can evaluate the three operational alternatives based on security, speed, and maintenance overhead:
Option A: Industry-Standard DNS CNAME to Vercel (Recommended)
RECOMMENDED • FASTEST
• Mechanism: Point social.urbangaon.com to Vercel via a single CNAME record in BigRock DNS.
• Domain Sovereignty: 100% on company domain (https://social.urbangaon.com). Zero third-party branding.
• Data Security: Database stays on MongoDB Atlas. Zero business data retained by Vercel.
• Timeline & Cost: 5 minutes setup • ₹0 / month (Included in Vercel Free Tier). Automated SSL and zero crashes.
Option B: UrbanGaon On-Premise Private NAS Server
100% PRIVATE • ZERO CLOUD
• Mechanism: Deploy the Docker / Node.js container directly onto UrbanGaon's physical office NAS server.
• Data Security: 100% physical custody inside company premises. No external compute platform involved.
• External Access: Requires configuring a Cloudflare Tunnel or local port-forwarding for external office access.
• Timeline & Cost: 2–3 hours engineering setup • ₹0 ongoing cost (Hardware already owned).
Option C: Upgrade BigRock Hosting / Enable Node.js Support
TRADITIONAL CPANEL
• Mechanism: Contact BigRock Support to enable Node.js v18+ in jailshell, or upgrade to a dedicated BigRock VPS.
• Data Security: Lives on BigRock hosting server alongside main corporate website.
• Limitation: Requires ongoing manual server patching, Apache configuration, and potential extra hosting fees.
• Timeline & Cost: 24–48 hours support SLA • Potential recurring server upgrade fee.
Key Talking Points for Sir / Leadership Review:
  • Zero Data Leakage: All proprietary business metrics remain in our encrypted MongoDB Atlas cloud regardless of whether BigRock or Vercel renders the page.
  • BigRock is Also a Third Party: BigRock is a commercial hosting vendor (Newfold Digital). Vercel carries significantly stricter corporate compliance (SOC2 Type II, ISO 27001).
  • 100% Brand Integrity: The URL in every browser, report, and executive device will always be https://social.urbangaon.com.
  • Zero Maintenance & ₹0 Cost: Option A eliminates server crashes, Apache 500/403 permission errors, and requires zero monthly budget.
🎯 Engineering Recommendation:
We recommend approving Option A (Vercel CNAME) for an instant, zero-cost, enterprise-grade deployment with full data security. Alternatively, if company policy strictly mandates air-gapped on-premise hardware, we can proceed with Option B (UrbanGaon NAS).

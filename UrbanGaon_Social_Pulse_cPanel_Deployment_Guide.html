Step-by-Step Execution Guide
Follow these steps directly inside your cPanel dashboard (as seen in your server screenshot):
1
Create the Subdomain in cPanel
  • In cPanel, scroll to Domains and click Domains (or Subdomains).
  • Click "Create A New Domain".
  • Domain Name: Enter social.urbangaon.com (or pulse.urbangaon.com).
  • Important: Untick "Share document root". Set document root to: public_html/social.
  • Click Submit. This generates an isolated, sandboxed website folder.
2
Deploy Node.js Backend via "Application Manager"
  • In your screenshot, locate the Software section ➔ Click on "Application Manager" (icon with 4 squares).
  • Click "Register Application" (or Add Application).
  • Fill in the fields:
    • Application Name: social-pulse
    • Deployment Domain: Select social.urbangaon.com
    • Base URL: / (or leave root for complete web application)
    • Application Path: social-pulse (folder where application lives)
    • Application Environment: Production
  • Under Environment Variables, click Add Variable:

FRONTEND DEPLOYMENT, SPA ROUTING & SSL
EXECUTION MANUAL • PART 2
4
Build & Upload Social Pulse to cPanel File Manager
  • On your local computer, build the optimized Next.js production bundle:
    npm run build
  • This creates the compiled web application in .next/ (total standalone size: ~34 MB).
  • In cPanel, open File Manager (under Files section).
  • Open the subdomain directory: public_html/social/.
  • Zip your local build folder (including .next, public, package.json, next.config.ts), upload the zip file, and click Extract.
  • Verify that .next/ and the public/ folder are directly inside public_html/social/.
5
Configure Client-Side SPA / Passenger Routing (.htaccess)
  • Create an .htaccess file inside public_html/social/ to ensure page refresh works on all dashboard tabs and Passenger routes traffic correctly:
  • <IfModule mod_rewrite.c> RewriteEngine On RewriteBase / RewriteRule ^index\.html$ - [L] RewriteCond %{REQUEST_FILENAME} !-f RewriteCond %{REQUEST_FILENAME} !-d RewriteRule . /index.html [L] </IfModule> # Passenger Node Startup (Optional Direct Mode): <IfModule mod_passenger.c> PassengerAppRoot /home/urbangaon/public_html/social PassengerAppType node PassengerStartupFile server.js </IfModule>
6
Enable Free 1-Click SSL Certificate (HTTPS)
  • In cPanel, scroll to Security ➔ click SSL/TLS Status.
  • Check the box next to social.urbangaon.com.
  • Click "Run AutoSSL". Within 2 minutes, your portal will have a secure green padlock (https://).
7
Final Verification & Health Check
  • Open https://social.urbangaon.com in any browser or smartphone.
  • Log in with admin credentials and verify all 4 live channels:
    • LinkedIn B2B Intelligence: Post impressions, member reactions, followers, and page views.
    • Instagram Consumer Engagement: Video/Reels views, accounts reached, and bio link clicks.
    • Facebook Community Hub: Impressions, unique reach, comments, and post shares.
    • Google Reviews & Local Intent: Live 4.7★ rating, total reviews, phone dials, and direction queries.
  • Test 1-Click Live Google Sync, multi-week Compare Matrix, and 1-Click Executive PDF Export.
